Overview

WaterWatch is a citizen-driven water quality monitoring platform developed to help identify, report, and analyze water pollution incidents across Delhi. The platform combines public participation, government water quality datasets, and Machine Learning-powered pollution analysis to create a centralized ecosystem for monitoring water bodies.

Users can report polluted water sources through survey submissions, analyze water quality using pH values, and upload images for AI-based pollution detection. The system also provides river-specific insights using authentic government datasets.

Live Application:  www.waterwatch.consulting￼

⸻

Features

Citizen Pollution Reporting

Citizens can submit reports regarding polluted water bodies through an online survey form.

Each report includes:

* Location details
* Water source information
* Pollution observations
* User remarks
* Timestamped submissions

All reports are stored securely in a MySQL database for monitoring and analysis.

⸻

AI-Based Water Quality Prediction

pH Analysis

Users can provide the pH level of a water sample to receive an estimated pollution classification generated by a Machine Learning model.

Machine Learning Module

pH Prediction Model

The pH-based model predicts pollution levels using water acidity and alkalinity values.

Input
{
  "ph": 7.2
}
{
  "pollution_level": "Moderate"
}
Image Classification Model

The CNN model analyzes uploaded water images and classifies them into predefined categories.

Supported Categories
Blue Water  -> Clear Water
Brown Water -> Polluted Water
Red Water   -> Polluted Water
Limitations

* Limited training dataset
* Supports only specific color-based pollution patterns
* Intended for demonstration and research purposes

Deployment Notes

Render Cold Start

The Machine Learning API is hosted on Render’s free-tier infrastructure.

As a result:

* Initial requests may experience delays.
* Temporary connection errors may occur while the service is waking up.
* The service generally becomes available after a short period.

This behavior is expected and does not indicate application failure.
